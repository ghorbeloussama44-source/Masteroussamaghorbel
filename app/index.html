Atelier Morphogenèse

d'après le mémoire de Mastère d'O. Ghorbel · EPT 2014

Une branche d'oranger simulée par un 0L-system stochastique piloté par une chaîne de Markov : chaque bourgeon f meurt, attend, s'allonge ou se ramifie selon la matrice H estimée dans le mémoire. Les entrenœuds grandissent ensuite selon les sigmoïdes mesurées. Faites glisser le temps pour voir développement et croissance avancer ensemble.

Scénario

Matrice de Markov H
  • B f → g  mort du bourgeon
  • C f → f  retard de croissance
  • D f → Y f  allongement
  • E f → X[f] f  ramification

Ligne = règle appliquée au pas précédent, colonne = règle suivante. Chaque ligne est renormalisée à 1.

Géométrie et croissance

Sigmoïdes K / (1 + a·e−r t) du mémoire, t = âge en itérations.

Le modèle en quatre équations

    

      
Système de réécriture (Proposition 2 du mémoire), axiome f :

      
A : g → g        B : f → g        C : f → f
D : f → Y f      E : f → X [f] f

      
Les règles sont les états d'une chaîne de Markov. Un bourgeon qui vient d'appliquer la règle i applique ensuite j avec la probabilité Hij.

      
Lecture du mémoire, en champ moyen (éq. 2.67–2.70), avec hn = h1 Hn−1 :

      
f(n+1) = f(n) · (1 − h_n(B) + h_n(E))

      
Lecture proposée ici : un processus de Galton–Watson multitype. La matrice moyenne compte les descendants par état, et la croissance asymptotique est sa racine de Perron ρ(M) :

      
M_ij = H_ij · [j ≠ B] + H_iE · [j = état latéral]       taux = ρ(M)

      
Pour la matrice de Fibonacci du mémoire (éq. 2.65), le champ moyen donne exactement φ ≈ 1.618, mais le vrai processus croît à ρ(M) ≈ 1.558, car un bourgeon qui se ramifie transmet son état à ses deux descendants. Le bouton « Caler la croissance sur φ » corrige H pour que ρ(M) = φ : c'est le « conditionnement Fibonacci » que le mémoire laissait en perspective.

      
Croissance des entrenœuds (éq. 2.178–2.182), t = âge en itérations :

      
Long(t) = 8 / (1 + 7.85 e^(−0.0075 t))      Rb(t) = 1.9 / (1 + 25.02 e^(−0.0338 t))
Rs(t) = 1.3 / (1 + 18.89 e^(−0.0385 t))     phyllotaxie ≈ 138.1° ± 4°     branchement ~ N(38°, 22°)
